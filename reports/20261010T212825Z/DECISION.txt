CRDT decision benchmark — stopped

Use native Rust results for Flutter/Rust decisions. JS/WASM results describe those runtimes separately. No mobile, Web or Flutter bridge integration has been measured.
Only configurations that pass the persistence/offline checks are candidates. A timeout or memory guard is an operational limit, not evidence of incorrect CRDT behavior.
Shallow snapshots, reset-to-JSON and destructive CRDT history pruning are excluded.
Raw serialized disk size and optional lossless Zstd-3 size are separate from actual database, fsync and encrypted storage costs.
Measured peak RSS includes runtime, resident CRDT state and operation buffers. Process peaks in upstream may include many replicas; offline report isolates each replica and stage.
Nested objects and arrays are covered by upstream JS/WASM tests; the native offline scenarios use text and flat scalar maps. Production rich-text, Unicode offset handling, schema migration and security still need integration validation.
